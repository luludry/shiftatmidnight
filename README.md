# Shift at Midnight Wiki

A Next.js + MDX fan-made wiki for Shift At Midnight, with English and Chinese content.

## Routes

- `/` — home
- `/doppelgangers` — guide index
- `/doppelgangers/the-dentist` — MDX article
- append `?lang=zh` for Chinese content

## Run locally

```bash
pnpm install
pnpm dev
```

Production verification:

```bash
pnpm lint
pnpm build
pnpm start
```
